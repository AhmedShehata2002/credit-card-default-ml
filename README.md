# Credit Card Default Prediction

ML classification model predicting loan default risk using decision trees and ensemble methods on a real-world credit dataset.

## Tech Stack
- Python
- scikit-learn
- Pandas, Matplotlib, Seaborn

## What it demonstrates
Ensemble methods (bagging, random forest, boosting) applied to financial risk modelling — with class imbalance handling, GINI-based feature importance, and precision/recall/ROC-AUC evaluation.

## How to run
```bash
cd notebook
jupyter notebook "Credit Risk Classification with Numeric and Categorical Attributes; Exploring Ensemble Methods in Cost Matrix Impact.ipynb"
```
